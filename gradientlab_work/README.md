# Gradient Lab — Bước 1: Scaffold giao diện

Bộ khung React + Vite + TypeScript + Tailwind CSS + Zustand, với giao diện dark/light, hero, sidebar tiến trình 6 chương và các thẻ chương.

## Chạy trên máy

Yêu cầu Node.js 20+.

```bash
npm install
npm run dev
```

Mở URL Vite hiển thị trong terminal (thường là http://localhost:5173).

## Build kiểm tra

```bash
npm run build
npm run preview
```

## Phạm vi hiện tại

Đây là **Bước 1** trong lộ trình Gradient Lab: scaffold ứng dụng, design system cơ bản và điều hướng chương. Các chương hiện là khung điều hướng để hoàn thiện lần lượt; xử lý ảnh, Sobel tương tác, histogram/Otsu, 3D và Canny thuộc các bước tiếp theo.
